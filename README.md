# Mi colección de juegos de mesa · By Oktapio

Web estática (HTML + CSS + JS, sin dependencias). Se publica con GitHub Pages.

- `data/games.js` → los datos de cada juego (`nota: null` = todavía sin jugar)
- `img/` → portadas en WebP
- Para agregar un juego: sumá un objeto en `data/games.js` y la imagen en `img/`.
